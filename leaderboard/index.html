Agent Trajectory Failure Detection

ATFD measures whether monitoring tools can detect failures in agent trajectories and correctly categorize them across a 7-category, 23-subcategory failure taxonomy. Evaluations run over three domains: tau-bench (tool-use agents), SWE-bench (coding agents), and a synthetic suite of adversarial trajectories.

All metrics include 95% bootstrap confidence intervals. Every submission must report cost to make the trade-off between accuracy and inference cost explicit.

How to Submit

  1. Run your tool against the ATFD datasets using the benchmark harness:
    atfd run --judge <your-adapter> --dataset all

  2. Produce a submission JSON file following leaderboard/schema.json. Validate it locally before submitting: 

    python leaderboard/validate.py my_submission.json

  3. Open a pull request to github.com/Galea-foo/atfd adding your file under results/submissions/<tool_name>.json. Include a link to reproduction code in the reproduction_url field.

  4. A maintainer will validate the submission, verify the methodology note, and merge it. The leaderboard updates on each merge to main.
